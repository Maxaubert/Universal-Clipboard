# Surface: Universal Clipboard app screens (mockups)

Scope: desktop first run, pairing, settings window, attention states; iPhone, iPad and Android pairing and tap actions. Mode: Operate. Code-led. Unattended run: no user answer was possible; the assigned direction was taken as is.

Audience and job: non-technical people pair their devices once and then forget the app. Constraint: never show clipboard content; few words; one sentence and one button per problem.

## Direction contract

THESIS: Pairing is a cloakroom ticket. One number, two matching halves; hand one half to the other device and they belong together. Refuses the category default of frosted glass, blue accent and device illustration cards.

OWN-WORLD: Cloakroom ticket stock. Cool pale ground, deep ink-navy text and primary buttons, ticket-red serial numerals for codes only, ticket tints (mint, butter, salmon, sky) as flat fields for state bands. Condensed tabular numerals (Barlow Condensed) for codes; system UI faces for everything else. Flat colour, no gradients, no glass. Native controls per OS.

STORY: The user understands "copy here, paste there", accepts permissions one row at a time, trades a ticket number between two devices, and sees one calm line that says it works.

FIRST VIEWPORT: Settings window 420 x 560: a full-width mint ticket band at top with state ("Working") and its proof line; the device list beneath with state marks; Add a device as the one filled button; Pause switch; collapsed Settings, Last activity, Help.

FORM: candidate 7 of 7 (cloakroom ticket). seed:cd63c5830d430798. Signature move: the code is shown as a ticket with a perforation, the QR on the tear-off stub; after pairing, both devices show the matched halves. Raises: state marks use one fill grammar (from Labanotation: solid = connected nearby, half = through the internet, outline = asleep, hatched = blocked); expired and removed things are stamped, never silently gone (from the jet-age ticket wallet); every state line carries its proof fact (from monochrome product marketing); every screen keeps one frame and scale (from the botanical folio); flat fills only (from the zoo map); tabular numerals for every code and time (from datamatics).
