# Privacy policy (draft)

Status: draft for an app in development. Not final.

- Universal Clipboard has no account and no cloud storage.
- Clipboard content goes only between your own devices. It is end-to-end encrypted. We cannot read it.
- The app holds only your newest copy, in memory. It writes no clipboard content to disk or to logs.
- When your devices cannot reach each other directly, an encrypted relay forwards the data. The
  relay sees IP addresses and encrypted bytes. It stores nothing.
- The app skips copies that a password manager marks as private.
- The app does not send analytics or crash reports.
- A daily update check fetches a public file from GitHub. GitHub sees your IP address, as for any download.

Contact: use the repository's private security reporting for privacy problems.
