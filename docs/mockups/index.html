Universal Clipboard: screen mockups

Static mockups for approval (milestone M8a). Made 2026-11-13 from section 2 of the spec. Open any page; nothing needs a server or a build.

Visual idea: the cloakroom ticket. Pairing works like a cloakroom: one number, two matching halves. The code is shown as a butter-yellow ticket with red numerals and a perforated stub that holds the QR code. After pairing, both devices show the matched halves. Everything else stays calm and plain: a pale ground, navy text and buttons, and one coloured band that says the state. Each OS keeps its own window frame, fonts and controls.

The app icon is a placeholder. Codes, names and times are examples. The QR codes are drawn patterns, not real codes.
