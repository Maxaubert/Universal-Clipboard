Errors: three ways

The code screen is the same in all three and follows the desktop's E1 "Shake, then clear": a wrong code gives one soft shake and red outlines, then the boxes empty one by one. The options differ in how the other problems show: no computer on this network, Local Network turned off, and a VPN that blocks the local network. Each problem is one sentence and one button. Each story ends on the code screen.
