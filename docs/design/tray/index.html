Tray and menu bar icon

Universal Clipboard gets a small icon next to the clock on Windows, in the menu bar on the Mac, and in the top bar or panel on Linux. A click opens a short native menu: the status, Open, Copy files, Copy folder, Pause, and Quit. Mockups for Max, 2026-11-17.

1. The icon

The app icon is Paper Layers: three stacked sheets with a clip tab. At 16 pixels three strokes run together, so there are two options. Pick one. The Mac draws the icon in black or white by itself (a template image), so the states use shape, never color. Each panel shows the icon at the size it ships at.

2. The menu

The menu is the system's own menu on every platform, so it looks right everywhere and works with the keyboard and screen readers. The first line is the status, in the words the app already uses. It is grey because it is a fact, not an action. On Windows a left click opens the window and a right click opens this menu. On the Mac and Linux a click opens the menu.

3. Behaviour

  • Open Universal Clipboard opens the window you know (Home). Closing the window keeps the icon.
  • Copy files... / Copy folder... open the system picker, like the buttons on Home. What you pick becomes the latest copy.
  • Pause / Resume work like the Pause button on Home.
  • Stop appears only while files move. It ends that transfer.
  • Quit Universal Clipboard closes the icon and stops syncing. Opening the app, or the next login, starts both again.
  • The icon starts at login next to the agent. A setting, Show icon in the menu bar (Mac) / Show icon in the taskbar (Windows, Linux), turns it off; uc settings set tray-icon off does the same.
  • The menu never shows clipboard content, only facts, as everywhere else in the app.
