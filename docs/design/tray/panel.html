2. Where it opens

Windows: above the icon, at the taskbar's corner. Mac: under the icon in the menu bar. It closes when you click anywhere else or press Esc. It is created when you click and closed when it hides, so it uses no memory while you do not look at it.

3. Behaviour

  • Copy files... / Copy folder... open the system picker. What you pick becomes the latest copy, at any size.
  • Sync switch: Pause and Resume.
  • Stop: the x next to the bar, only while files move.
  • Open Universal Clipboard opens Home. The sliders button opens Settings. The power button quits: the icon goes away and syncing stops until you open the app or log in again.
  • Linux: GNOME and KDE can only show a plain menu from such an icon, not a panel. There the icon gets a short menu: the state line, Open, Copy files..., Copy folder..., Pause, Quit.
  • A setting Show icon in the menu bar (Mac) / Show icon in the taskbar (Windows, Linux), default on, and uc settings set tray-icon off.
