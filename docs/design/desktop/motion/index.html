Motion mockups

New motion for Universal Clipboard. Each page shows one moment of the app, with several options side by side. Every option plays on its own and loops. The look stays the same as the app.

Made 2026-11-14. 38 options in 5 groups.

  • Setup flow The whole first run, from Welcome to Connected, with the moves between screens. S1 to S77 options
  • Paired The moment two devices meet. Every option ends on the real Connected screen. P1 to P88 options
  • Errors Wrong code, old code, too many tries, no network and a device that cannot be found. E1 to E88 options
  • Home: this PC Ways to show this PC apart from the other devices, so it no longer looks like one more tile. H1 to H88 options
  • Sync activity A copy is sent or arrives, Pause and Resume, a device needs help, and a code renews. A1 to A77 options

How to choose

  1. Open a page. Watch each option play, or press Replay.
  2. Press Reduced motion at the top to see the calm version of each option.
  3. Reply with the ids you like, for example P3, E5, S2, H4, A1.
  4. Mixing is fine. You can pick more than one per page, or say which part of an option you like.

The shared pieces (screens, colours, timing) are on the motion kit page. Open any page straight from the folder in a browser. It works offline.
