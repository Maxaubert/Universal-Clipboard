# Motion mockups (2026-11-14)

Animation options for the desktop app, made for Max's brief of 2026-11-14: sleek motion for the
setup, paired and error screens, and a Home panel where this PC no longer looks like one more tile.
The look stays the locked design (`../README.md`). Only the motion and some imagery are new.

## How to view

Open `index.html` in a browser (double-click it, or `file:///.../motion/index.html`). It links to
every page. Everything is local and works offline. No server is needed.

Each page has Replay all, Reduced motion and Pause all at the top, and a Replay button under each
option. URL switches for checks: `?reduce=1` (reduced motion) and `?t=1200` (freeze at 1200 ms).

## What is here

| Page | Options | What it shows |
|---|---|---|
| `setup.html` | S1 to S7 | The whole first run, Welcome to Connected |
| `paired.html` | P1 to P8 | The Connected moment |
| `errors.html` | E1 to E8 | Wrong code, old code, too many tries, no network, device not found |
| `home.html` | H1 to H8 | Ways to show this PC apart from the other devices |
| `activity.html` | A1 to A7 | Copy sent or received, Pause and Resume, Needs attention, code renew |
| `kit.html` | K1 to K7 | Static copies of the real screens that the pages build on |

Shared files: `kit.css` (tokens and gallery layout, copied from `apps/desktop/src`), `kit.js`
(replay, loop, reduced motion, pause, seek), `art.js` (device art), `fonts/` (Figtree).

## Rules the options follow

- Calm, smooth motion that is easy to follow through a magnifier. No flashing, no fast small details.
- Only transform, opacity, SVG strokes and clip-path, with WAAPI or CSS. No canvas, WebGL or libraries.
- Every option has a reduced-motion version that still shows the state change, with fades only.
- Copy never shows clipboard content, only facts like "Text, from Max's Mac, 2 minutes ago". No em-dashes.

## How to choose

Reply with the option ids you like, for example "P3, E5, S2, H4, A1". Mixing is fine.

## Notes

- Some copy in the mockups is new and not yet in `apps/desktop/src/lib/strings.ts`, for example
  "Sync is paused", "Works for 10 minutes", "This code no longer works. The QR code still works."

  from now on.
