# Security policy

Universal Clipboard is in development and has no release yet.

## Report a problem

Please report a security problem in private. Use GitHub's "Report a vulnerability" button on the
Security tab of this repository. Do not open a public issue for it.

Say what you found, how to repeat it, and which version or commit you used. Please give the
maintainer a reasonable time to fix the problem before you tell others.

## Scope

The sync protocol, the pairing code, the key storage and the update check. The design goals are in
`docs/plan/2026-11-13-spec-and-plan.md`.
