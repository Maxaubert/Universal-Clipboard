# Universal Clipboard

Copy on one device, paste on another. End-to-end encrypted, no account, no cloud.

**Status: in development.** Nothing is released yet.

| Platform | Plan |
|---|---|
| Windows 11 | v1 |
| macOS 14+ (Apple silicon) | v1 |
| Linux (KDE and X11 desktops) | v1 |
| iPhone, iPad, Android | v1, with the limits that iOS and Android set |

The product spec and build plan are in [docs/plan](docs/plan/2026-11-13-spec-and-plan.md).
The privacy policy draft is in [docs/privacy.md](docs/privacy.md).
